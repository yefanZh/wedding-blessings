# Wedding Blessings

一个适合直接部署到 GitHub Pages 的单页婚礼祝福网站。

## GitHub Pages 部署

1. 打开仓库的 `Settings → Pages`。
2. 在 `Build and deployment` 中选择 `Deploy from a branch`。
3. Branch 选择 `main`，Folder 选择 `/ (root)`。
4. 保存后等待 GitHub Pages 完成部署。

## 修改祝福语

打开 `index.html`，搜索 `class="blessing"` 即可修改内容。

为了实现无缝循环，祝福语列表在下半段重复了一遍，修改时两处保持一致即可。
